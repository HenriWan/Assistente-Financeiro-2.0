Recuperar acesso admin

Por segurança, a senha do admin não fica salva visível no site. Para redefinir, altere a variável ADMIN_PASSWORD no Google Cloud Run.

Use este comando no terminal:

gcloud run services update assistente-financeiro-2-0 --region southamerica-east1 --update-env-vars ADMIN_PASSWORD=NOVA_SENHA_FORTE

Depois faça login novamente usando o usuário admin e a nova senha.
